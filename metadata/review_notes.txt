Open Journey and select level 1 or Play today. Tap two neighbouring pieces, or swipe, to swap them. Hint marks a valid move. Save and close, then reopen the puzzle to resume. Scroll to Seasonal collection to find the twelve monthly boards. Open Collection for candy looks and You for the calendar, optional local reminders and file transfer. No login or external API key is required. Notifications are optional. The game runs offline and the widget reads a shared App Group snapshot.
